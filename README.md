# Flavora

Домашний кулинарный блокнот: каталог рецептов с пошаговыми иллюстрациями, избранное и меню на неделю.

- Репозиторий: https://github.com/sonjiwu2/flavora
- Сайт: https://sonjiwu2.github.io/flavora/

## Локальный запуск

```bash
npm ci
npm run serve
```

Сайт откроется по адресу `http://127.0.0.1:5510/flavora/`. Сборка не нужна: это статические HTML, CSS
и JavaScript-модули.

Устройство проекта описано в [docs/architecture.md](docs/architecture.md).
