# Flavora

Домашний кулинарный блокнот: 50 рецептов с пошаговыми иллюстрациями, избранное и меню на неделю.
Сайт сделан на чистых HTML, CSS и JavaScript и работает как статические страницы GitHub Pages.

- Сайт: https://sonjiwu2.github.io/flavora/
- Репозиторий: https://github.com/sonjiwu2/flavora

## Что умеет сайт

- **Каталог.** 50 рецептов в девяти категориях, поиск по названию и ингредиентам, сортировка.
- **Фильтры.** Время приготовления, тип блюда, «Продукты дома» с подсчётом совпадений и режимом
  «Только из выбранного», исключение продуктов.
- **Рецепт.** Фотография блюда, ингредиенты с пересчётом на нужное число порций, шесть шагов с
  иллюстрациями и таймерами.
- **Избранное.** Сохранённые рецепты с поиском и сортировкой.
- **Меню на неделю.** Завтрак, обед и ужин на каждый день: добавление, замена, перемещение и
  удаление блюд, переключение недель.
- **Оформление.** Светлая и тёмная тема, рукописные шрифты Marck Script и Caveat, адаптивная
  вёрстка от телефона до широкого монитора, уменьшенное движение по настройке.

Избранное, меню и настройки хранятся в localStorage браузера. Сервера, регистрации и сбора данных
нет.

## Соответствие учебному заданию

| Требование                                    | Где это в проекте                                                    |
| --------------------------------------------- | -------------------------------------------------------------------- |
| HTML: заголовок, разделы, изображение, ссылка | `index.html`, экраны каталога, рецепта, избранного и меню            |
| CSS: собственные цвета, шрифты, отступы       | `styles/tokens.css` и остальные файлы в `styles/`                    |
| JavaScript: кнопки с разными действиями       | Тема, избранное, фильтры, порции, таймер, меню — модули в `scripts/` |
| Публикация на GitHub Pages                    | Ветка `main`, корень репозитория                                     |

Каталог из 50 рецептов, фильтры, избранное, меню на неделю, тёмная тема и автоматические проверки
сделаны сверх обязательных требований.

## Локальный запуск

```bash
npm ci
npm run serve
```

Сайт откроется по адресу `http://127.0.0.1:5510/flavora/`. Сборка не нужна. Локальный сервер отдаёт
сайт под тем же путём `/flavora/`, что и GitHub Pages.

## Проверки

```bash
npm run lint
npm run format:check
npm run test:unit
npm run test:e2e
```

Сценарии `test:e2e` запускаются в Chromium, Firefox, WebKit и в мобильном профиле; перед первым
запуском установите браузеры командой `npx playwright install`.

## Устройство проекта

Архитектура, маршруты, формат данных и общие модули описаны в
[docs/architecture.md](docs/architecture.md).

| Каталог    | Содержимое                                                  |
| ---------- | ----------------------------------------------------------- |
| `scripts/` | Роутер, хранилище состояния, данные рецептов, экраны        |
| `styles/`  | Токены оформления, базовые стили, компоненты, стили экранов |
| `assets/`  | Шрифты, фотографии блюд, иллюстрации шагов, иконка          |
| `tests/`   | Модульные тесты и сценарии Playwright                       |
| `tools/`   | Локальный сервер, снимки страниц, подготовка изображений    |
