# Обложки блюд

Фотографии блюд в `assets/dishes/` предоставлены владельцем проекта Flavora специально для этого
сайта: по одной обложке на каждый из 50 рецептов.

В репозитории лежат только оптимизированные копии в формате WebP — `<id-рецепта>-480.webp`
(480×320) и `<id-рецепта>-960.webp` (960×640). Исходные файлы в репозиторий не входят.

Копии собирает `tools/build-dish-covers.mjs` по соответствию «рецепт — исходный файл» из
`tools/dish-covers.json`:

```
node tools/build-dish-covers.mjs <папка с исходными обложками>
```
